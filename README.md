# Redes-SOHO
Proyecto en Cisco Packet Tracer para simular la creacion de redes SOHO y servicios IPV4

## Integrantes
- Andrés Felipe Ramos
- Sara Velandia
- Juan Manuel Castro

## Resumen
Se diseñó, implementó y verificó una red SOHO utilizando Cisco Packet Tracer integrando conceptos de LAN, WLAN, VLAN, IPv4, subneteo, interconexión WAN y servicios de red.
